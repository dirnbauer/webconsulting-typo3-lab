# Site Package

TYPO3 14-only site package/provider extension for Webconsulting TYPO3 Lab.

This extension owns the shared project configuration that used to be split
across `adminpanel_defaults` and `visual_editor_defaults`.

## Composer Package

| Field | Value |
|---|---|
| Composer name | `webconsulting/site-package` |
| TYPO3 extension key | `site_package` |
| Extension version | `14.0.0` |
| TYPO3 support | `14.3.0-14.99.99` |
| PHP support | `^8.2` |
| Package type | `typo3-cms-extension` |
| Namespace | `Webconsulting\SitePackage` |

TYPO3 13 support has been removed from Composer metadata. TYPO3 14.3+ release
metadata is Composer-only for this package.

## What This Package Provides

- Shared TYPO3 Site Sets for the demo sites:
  - `webconsulting/site-package`
  - `webconsulting/site-package-search`
  - `webconsulting/site-package-blog`
  - `webconsulting/site-package-blog-bootstrap`
  - `webconsulting/site-package-camino`
- Frontend Admin Panel defaults:
  - Enables `config.admPanel`.
  - Enables Admin Panel access for backend users via `Configuration/user.tsconfig`.
- Shared editor defaults:
  - Sets `RTE.default.preset = cowriter`.
  - Registers the Cowriter preload middleware for Visual Editor edit mode.
- Shared template paths:
  - Adds Desiderio partial root paths for EXT:news and EXT:blog.
  - Provides Desiderio template path overrides for Blog sites.
- Shared Solr defaults:
  - Depends on the existing `webconsulting/solr-defaults` Site Set.
  - Adds the numbered pagination partial path.
  - Removes the stale EXT:solr 14 `solr-jquery` include.
- MCP table configuration:
  - Exposes `tt_address` as `Addresses` for MCP dynamic tools.

## Feature Inventory

| Area | Implementation |
|---|---|
| TYPO3 version | TYPO3 `14.3.0-14.99.99`, PHP `^8.2`. |
| Site Sets | Five Site Sets covering base defaults, search, Blog, Blog Bootstrap, and Camino. |
| Admin Panel | `config.admPanel` TypoScript plus backend user TSconfig access defaults. |
| RTE | Global `cowriter` RTE preset. |
| Visual Editor | PSR-15 middleware that preloads `netresearch/t3-cowriter` JavaScript modules before Visual Editor persistence middleware. |
| Solr | Shared Solr Site Set dependency, numbered pagination partial path, and cleanup of the stale EXT:solr 14 jQuery include. |
| Desiderio | Shared partial/template path overrides for EXT:news, EXT:blog, and Blog rendering. |
| MCP | `tt_address` table metadata exposed as `Addresses`. |

## Removed Packages

The following local packages were consolidated into this package and removed:

- `packages/adminpanel_defaults`
- `packages/visual_editor_defaults`

Composer now only needs `webconsulting/site-package` for these shared project
defaults.

## Verification

After changing this package, run the project-level checks from the repository
root:

```bash
composer validate --no-check-publish
Build/Scripts/runTests.sh -s phpstan
Build/Scripts/runTests.sh -s ci
ddev exec vendor/bin/typo3 lint:yaml config/sites packages/site_package/Configuration/Sets
ddev exec vendor/bin/typo3 extension:setup
ddev exec vendor/bin/typo3 cache:flush
```

PHPStan runs at `level: max` with the TYPO3-specific
`saschaegerer/phpstan-typo3` extension.
