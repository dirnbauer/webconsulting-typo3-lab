The lab's backend login in the webconsulting design of track.webconsulting.at and Ledger: a deep teal brand column (logo, environment, what the backend is for) and a pale canvas with one white form surface. It replaces the Core layout EXT:backend Layouts/Login.fluid.html for the login (EventListener/UseLabBackendLoginLayout) and the password-reset pages (page TSconfig templates.typo3/cms-backend). Everything the Core layout does is kept: the login providers render their "loginFormFields" and "ResetPassword" sections here, with the Core form, its hidden fields, ids, error and cookie notices, the provider switch, the system news, the copyright notice and the referrer-check link.
