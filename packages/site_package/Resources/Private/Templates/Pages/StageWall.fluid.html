The Desiderio start page "Stage and Wall" (backend layout pagets__StageWall, set on the site's root page). Same content area and markup as Desiderio's start page template (Presets/Corporate DesiderioStartpage): one screen-reader-only h1, then every element as it renders anywhere else. The elements get data attributes with their place (Classes/StartPage/ StageWallPlan): a hero first and a film after it form the stage, all other elements are tiles of a 12-column wall whose width the editor picks in the element's "Layout" field. The stylesheet places by those attributes; it is loaded here, so only this page in its languages gets it, and it is in the head before the first paint. The script only moves the stage light after the pointer in dark mode. The lab's start page switch (#home=classic|b|c, Middleware/ HomeProposalSwitch) sets data-lab-home on the html element; the stylesheet stands down then and the plain start page shows, or proposal B or C on it.
