The child's link is the booking target. Where a mentor has no slots left, the record simply has no link and the card renders without a button — a dead "request a session" is worse than no button at all, and it is the state an editor is actually in for most of a term. Every booking button says the same three words, so each carries the mentor's name as text only a screen reader hears. A list of six identical links is unusable to anybody navigating by link, and putting the name in the visible label would make the buttons ragged. The subjects are tokens split on the semicolon the editor typed. There is no field for a list of subjects, and adding a second record type for the sake of punctuation would cost more than it is worth. The alt names the mentor: a reader picks a person on this band, and a card whose face belongs to nobody is a card nobody picks.
