Two branches for one field. In the frontend the code is escaped and left exactly as typed, because f:render.text would turn every newline into a break element, and inside preformatted text that break is a line the reader would copy. In the editor the same field does go through f:render.text, so the block becomes an inline plain-text editable — there the breaks are the point.

{data -> f:render.text(field: 'header')}
{data -> f:render.text(field: 'caption')}
 
{data -> f:render.text(field: 'text')}
 
{data.text -> f:format.htmlspecialchars()}

{data -> f:render.text(field: 'note')}
