The dates are typed, not taken from the record's timestamp — and that is the point of the element. A timestamp says when a field last changed, which a corrected typo also does; this line says when a human last read the page and decided it was still correct. A real description list, so each date keeps the label that explains it rather than becoming a loose number in a row. The short value is capped at twenty-four characters, which a date fits and a department name often does not, so a row with no value falls back to its longer text.
