The badges are icon links from the shared library and the QR code is an image an editor uploaded, so opening the page fetches nothing from a store and no request tells anybody which app this visitor was shown. Each badge names its store in text: a badge that is only artwork is a link with no accessible name, and on a desktop the QR code is the only part of the band a reader cannot use at all.
