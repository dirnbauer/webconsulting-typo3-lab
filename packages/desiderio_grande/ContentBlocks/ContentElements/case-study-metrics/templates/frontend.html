A description list, because that is what this band is: a set of measures and the values they took. The value is printed above its label, which a definition list cannot express in source order, so the visual order is set in the stylesheet instead of by reversing the markup. The note carries the measurement period. Figures without a period invite the reader to distrust all of them, including the ones that are true.
