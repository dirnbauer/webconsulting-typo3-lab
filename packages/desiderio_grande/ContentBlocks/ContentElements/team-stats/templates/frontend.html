The figures are a description list: each value is defined by the label under it, and that is the one relationship a screen reader needs in order to read "fifty-eight" as something other than a loose number. The value comes before its label in the source as well as on screen — a definition list is read term first, and here the number is the term the sentence beneath explains. The icon tile carries the semantic key rather than a glyph, so swapping the icon library never reaches into a template.
