Nothing is computed here. The child's text field holds the starting value in the editor's own words — "was 2.4 %", "vorher 2,4 %" — and the value field holds where it ended up. The arrow between them is drawn by the stylesheet and hidden from assistive technology, because the two labels already say which way round the pair reads. That also keeps the claim with the person making it: an element that subtracted one figure from the other would be publishing arithmetic nobody approved.
